# Examples

Compile-only lmcode programs, one per scenario. The fixtures compile through the compiler library and run against the `lmproxy` host:

```sh
LMCODE_COMPILER_MODULE=/path/to/lmctl-mono/lmscript/dist/dsl.js node scripts/compile-lmcode-fixture.mjs examples/parse-url.lms tests/fixtures/lmcode/parse-url.dslb
lmproxy --lmcode tests/fixtures/lmcode/parse-url.dslb
```

The compile-only source declares its host schema. Fixture bytes are pinned under
`tests/fixtures/lmcode/` and generated by the compiler-library tool.

- `parse-url.lms` — parse several URLs and print their components
- `inspect-request.lms` — parse an embedded HTTP/1.1 request, print first line and headers
- `inspect-response.lms` — parse an embedded HTTP/1.1 response, chase its Location header
- `percent-encoding.lms` — percent-decode and re-encode a URL path

`./test.sh` type-checks every source and runs its pinned bytecode fixture as part of the suite.
